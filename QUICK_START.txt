================================================================================
  🚀 QUICK START - Meeting Cost Calculator (React + Tailwind SaaS Dashboard)
================================================================================

⏱️  TAKES 2 MINUTES TO GET RUNNING

STEP 1: Open Terminal/Command Prompt
  cd "Meeting cost calculator"

STEP 2: Install Dependencies
  npm install

STEP 3: Start Development Server
  npm run dev

✅ Done! Browser opens automatically at http://localhost:5173

✨ Beautiful SaaS Dashboard with:
  • Real-time cost calculation
  • Glassmorphism UI design

  • Fully responsive (mobile, tablet, desktop)
  • Dark theme with cyan/violet/emerald accents

================================================================================
  🎯 HOW TO USE
================================================================================

1. ADD PARTICIPANTS
   • Enter name (e.g., "Alice Johnson")
   • Enter hourly rate (e.g., "150")
   • Click "Add Person"

2. SET MEETING TIME
   • Use slider or type in duration
   • Or click quick buttons (15m, 30m, 60m, 90m)

3. ENTER MEETING AGENDA
   • Type what the meeting is about
   • System detects keywords automatically

4. SEE RESULTS
   • Total cost displayed with animation
   • Smart recommendation (🟢 good, 🟡 optimize, 🔴 expensive)
   • Cost breakdown per participant
